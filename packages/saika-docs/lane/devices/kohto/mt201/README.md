# MT201 受信互換仕様（Saika Lane）

[文書一覧](../../../../INDEX.md)

Saika Lane が `MT201` デバイス設定で受理する入力と、着弾への変換を説明します。メーカーの公式通信仕様ではありません。

| 項目              | 内容                                                            |
| ----------------- | --------------------------------------------------------------- |
| 製品識別          | 興東電子株式会社 `MT-201`                                       |
| メーカー公開情報  | [ビームライフル装置](https://kohto.co.jp/beam03.html)           |
| Saika デバイス ID | `MT201`                                                         |
| Saika 対応種目    | `BEAM_RIFLE_10M`                                                |

標的面と採点データについては [標的・採点データ](../../../../common/TARGET_SPEC.md) も参照してください。BPT-216 との接続設定やデータ形式の違いは、[受信処理の比較](../bpt216/README.md#6-mt-201とのシグナル受信処理比較bp-217-if) を参照してください。

## 2. Saika 側のシリアル設定

Saika Lane の既定値は次のとおりです。

| パラメーター   | Saika 既定値 |
| -------------- | -----------: |
| ボーレート     |         9600 |
| データビット   |            8 |
| ストップビット |            1 |
| パリティ       |       `none` |

設定値は [`targetDeviceDefinitions.ts`](../../../../../saika-lane/src/main/modules/target/domain/targetDeviceDefinitions.ts) で定義します。接続先は OS が列挙したシリアルポートから選択します。

Saika は接続時と試射・本射の切り替え時に、終端文字なしの ASCII `S` / `R` を送ります。

## 3. 受信レコード

### 3.1 フレーミング

[`KohtoFormatParser`](../../../../../saika-lane/src/main/modules/target/infra/parsers/KohtoFormatParser.ts) は受信バイト列を UTF-8文字列として読み、LF（`\n`）で行に分割します。空行は無視し、未完行は次の受信まで保持します。パーサーが前後の空白を除去するため、CRLF も受理します。行は可変長で、各フィールドを次節の条件で検査します。

着弾音は、行全体の検査・変換が成功すると 1 発につき 1 回鳴ります。分割された受信断片や不正な行では鳴りません。音は保存完了の通知ではないため、記録は画面の着弾と得点で確認します。

### 3.2 正規形

次の形式で入力します。

```text
R 9.7 0250 FF5F 70
R10.9 0000 0000 70
```

構文の概要は次のとおりです。

```text
record   = mode, optional-space, score, space, x-hex, space, y-hex, space, check-hex
mode     = "R" | "S"
score    = decimal-number
x-hex    = 4HEXDIG
y-hex    = 4HEXDIG
check-hex = 2HEXDIG
```

- モードと得点の間の空白は省略できる。
- 後続フィールドの間には1文字以上の空白が必要である。
- 座標とチェック欄の16進文字は小文字も受理し、内部では大文字へ正規化する。
- モードは大文字 `R` または `S` を使う。
- 送信側は得点を `0.0`〜`10.9` の小数点1桁で生成すること。最終的な範囲検査は Saika の`Score` 値オブジェクトが行う。

パーサーが正規形以外の空白や数値表現を受理する場合もありますが、互換性は保証していません。送信側は上記の形式を使ってください。

### 3.3 フィールド

| フィールド | 受理形式       | Saika での扱い                              |
| ---------- | -------------- | ------------------------------------------- |
| mode       | `R` または `S` | `R` → `MATCH`、`S` → `SIGHTING`             |
| score      | 数値文字列     | `round(score × 10)` で0.1点単位の整数へ変換 |
| x          | 16進4桁        | 符号付き16ビットへ変換後、mm へ変換         |
| y          | 16進4桁        | 符号付き16ビットへ変換後、mm へ変換         |
| check      | 16進2桁        | 形式だけを検査し、`Shot` には保存しない     |

チェック欄は2桁の16進数かどうかだけを検査し、値は照合しません。形式が正しくても、転送データの完全性は保証されません。

## 4. 座標変換

[`MT201CoordinateConverter`](../../../../../saika-lane/src/main/modules/target/adapters/mt201/MT201CoordinateConverter.ts)は、X と Y を16ビットの2の補数として読み、次の式で Saika の mm 座標へ変換します。

```text
signed = hex < 0x8000 ? hex : hex - 0x10000
millimetres = signed / 150
```

| 16進値 | 符号付き値 | Saika 座標       |
| ------ | ---------: | ---------------- |
| `0000` |          0 | `0 mm`           |
| `0250` |        592 | 約 `3.947 mm`    |
| `FF5F` |       -161 | 約 `-1.073 mm`   |
| `8000` |     -32768 | 約 `-218.453 mm` |
| `7FFF` |      32767 | 約 `218.447 mm`  |

Saika は受信した X/Y の符号を反転せず、そのまま `ImpactPoint(x, y)` に格納します。画面上の左右・上下が実際の着弾方向と一致するかは、機器の設置方向を含めて実機で確認してください。

## 5. `Shot` への変換

[`MT201Adapter`](../../../../../saika-lane/src/main/modules/target/adapters/MT201Adapter.ts) は、受信モードの `R` を本射、`S` を試射として `Shot` を生成します。Lane の現在モードと異なる場合も、受信モードを優先します。座標は前節の式で mm へ変換しますが、次のミスの特殊値は座標なしとして記録します。

### 5.1 ミス

次の3条件がすべて成立するときだけ、Saika はミスとして扱います。

| score | x      | y      | 生成結果                                   |
| ----- | ------ | ------ | ------------------------------------------ |
| `0.0` | `7FFF` | `7FFF` | 得点0、`impactPoint: null`、inner ten なし |

座標の一方だけが `7FFF`、または得点が0以外の場合は、この特殊判定には入りません。

### 5.2 得点

受信得点を `Math.round(score × 10)` で整数化します。記録時には装置得点を優先し、座標からの計算値も照合用に保持します。インナー 10 は座標から判定します。共通の採点処理は [標的・採点データ](../../../../common/TARGET_SPEC.md#得点の扱い) を参照してください。

## 6. エラー条件

次の入力は変換エラーまたは検証エラーになる。

- 必須フィールドが不足している、または余分な非空白文字がある。
- モードが大文字 `R` / `S` 以外である。
- 得点を有限数として解釈できない。
- X/Y が16進4桁ではない。
- チェック欄が16進2桁ではない。
- 変換後の得点が Saika の範囲 `0`〜`109` を外れる。
- 座標から有効な `ImpactPoint` を生成できない。

## 8. 接続時の切り分け

1. Saika 設定で `MT201` と意図したシリアルポートが選択されているか確認する。
2. 設定値が9600 baud、8 data bits、parity none、1 stop bit になっているか確認する。
3. 受信行が LF または CRLF で完結しているか確認する。
4. モード、得点、X、Y、チェック欄が §3 の形式か確認する。
5. 解消しない場合は [問い合わせに必要な情報](../../../../GETTING_STARTED.md#問い合わせに必要な情報) を確認する。

## 9. 検証状態

自動テストは構文検査、座標変換、ショット生成、改行による分割に加え、試射・本射それぞれの分割受信から保存・着弾通知までを対象とします。実機では利用する OS・変換器・機器の組み合わせで、接続、試射・本射の切り替え、連続着弾、再接続を確認します。
