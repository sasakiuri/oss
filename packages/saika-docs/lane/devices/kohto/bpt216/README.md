# BPT-216 受信互換仕様（Saika Lane）

[文書一覧](../../../../INDEX.md)

Saika Lane が BPT-216 の接続設定で受理する入力形式と、着弾への変換を説明します。メーカーの公式通信仕様ではありません。

## 1. 対応機器

製品情報は、メーカーの[ビームピストル装置ページ](https://kohto.co.jp/beam04.html) を参照してください。

| 項目                | 内容                                                |
| ------------------- | --------------------------------------------------- |
| Saika デバイス ID   | `BPT216`（`BP-217 I/F`）、`BPT216_RS232`（RS-232C） |
| 旧設定からの移行 ID | `BP216`                                             |
| Saika 対応種目      | `BEAM_PISTOL_10M`                                   |

旧設定の `BP216` は `BPT216` へ移行します。旧種目が `BEAM_RIFLE_10M` なら `BEAM_PISTOL_10M` に変わります。旧競技が `BR60S` または未設定なら `BP60` に変わります。

## 2. シリアル設定

### 2.1 BP-217 I/F（`BPT216`）

| パラメーター   |     値 |
| -------------- | -----: |
| ボーレート     | 115200 |
| データビット   |      8 |
| ストップビット |      1 |
| パリティ       | `none` |
| フロー制御     |   なし |
| 文字コード     |  ASCII |

標的からホストへのデータは改行区切りです。Saika は LF を終端として扱い、CRLF も受理します。途中で分割された行は次の受信チャンクまで保持します。

### 2.2 RS-232C（`BPT216_RS232`）

| パラメーター   |     値 |
| -------------- | -----: |
| ボーレート     |   9600 |
| データビット   |      8 |
| ストップビット |      1 |
| パリティ       | `none` |
| フロー制御     |   なし |
| 文字コード     |  ASCII |

RS-232C プロファイルも LF 区切りで受信し、CRLF および行端の ASCII 空白を受理します。途中で分割された行は次の受信チャンクまで保持します。

## 3. 受信フレーム

### 3.1 BP-217 I/F（`BPT216`）

通常フレームは6個以上の CSV フィールドを持ちます。

```text
score,x,y,reserved-1,reserved-2,state[,version]
```

| 位置 | フィールド | Saika での扱い                                                   |
| ---: | ---------- | ---------------------------------------------------------------- |
|    0 | score      | `0.0`〜`10.9`、0.1点単位。末尾ゼロ付きの `9.70` / `10.90` も受理 |
|    1 | x          | 符号付き10進整数、単位は0.01mm                                   |
|    2 | y          | 符号付き10進整数、単位は0.01mm                                   |
|  3–4 | reserved   | ショット生成には使用しない                                       |
|    5 | state      | `T`（確定着弾）、`R`（Ready）、`B`（軌跡）                       |
|    6 | version    | 任意。パース結果に保持する補助情報                               |

Saika は第6フィールドが `T` の行だけを着弾パーサーへ渡します。`R`、`B`、不明な state の行は破棄し、記録・描画・採点・着弾音の対象にしません。X 欄の `9999` は状態通知の特殊値なので、`T` 行に現れても着弾座標へ変換しません。

得点は0.1点単位の整数へ変換します。1点未満の値は0点に正規化します。座標は次式で Saika の mm 座標へ変換します。

```text
x_mm = x / 100
y_mm = y / 100
```

座標系は X 正が右、Y 正が上であり、Saika 内の Cartesian 座標と同じなので符号反転は行いません。

### 合成入力例

```text
0.0,0,0,0,0,R
0.0,120,-80,0,0,B
10.90,123,-456,0,0,T
0.0,9999,0,0,0,R,2.01
```

3行目だけが、10.9点、X=`1.23mm`、Y=`-4.56mm` の着弾になります。

### 3.2 RS-232C（`BPT216_RS232`）

RS-232C の受信形式は、次の固定幅 ASCII フレームです。

```text
P<score> <xHex> <yHex> <checksum>
```

- 0.0〜9.9点では `P 9.9` のように `P` の直後へ空白を置き、10.0〜10.9点では `P10.0` のように空白を置かない。得点は0.1点刻みである。
- `xHex` と `yHex` は4桁の16進数で、符号付き16ビット整数として解釈する。単位は0.01mm である。
- `checksum` は2桁の16進数である。`P` からチェックサム直前の区切り空白までの ASCII バイトを加算し、下位8ビットを大文字16進2桁にした値と一致しなければ破棄する。
- 1点未満は0点へ正規化する。座標は `BP-217 I/F` と同じく `raw / 100` mm へ変換する。

`P`以外で始まる MT-201形式、桁数が異なるフレーム、不正なチェックサムは着弾として通知しません。

次は合成入力例です。

```text
P10.9 007B FE38 47
```

得点 10.9 点、X=1.23 mm、Y=-4.56 mm として変換します。チェックサム `47` は末尾の区切り空白を含む加算値です。送信時は LF を付けてください。

## 4. モードコマンド

Saika は接続時および試射・本射の切替時に、終端文字なしの ASCII 1バイトを標的へ送ります。

| Saika モード | 送信バイト |
| ------------ | ---------- |
| 試射         | `S`        |
| 本射         | `R`        |

受信フレーム自体には試射・本射の区別がないため、生成する `Shot.mode` には Saika の現在モードを使います。

## 5. 標的と採点

`BEAM_PISTOL_10M` は [JRSF_BP_10M](../../../../common/TARGET_SPEC.md#jrsf_bp_10m10m-ビームピストル標的)を使用します。標的環は10m エアピストルと同じで、仮想弾径4.5mm（半径2.25mm）として描画・座標採点します。BPT-216が通知した得点は `deviceScore` として保持し、BP60では整数圏採点を適用します。

## 6. MT-201とのシグナル受信・処理比較（BP-217 I/F）

接続設定や記録の確認に影響する差を示します。MT-201 の詳細は [受信互換仕様](../mt201/README.md) を参照してください。

| 項目             | MT-201                     | BPT-216 `BP-217 I/F`               |
| ---------------- | -------------------------- | ---------------------------------- |
| ボーレート       | 9600                       | 115200                             |
| 得点・座標の形式 | 空白区切り、座標は 16 進数 | CSV、座標は 10 進整数              |
| 座標変換         | raw / 150 mm               | raw / 100 mm                       |
| 試射・本射       | 受信行の `S` / `R` を使用  | Lane の現在モードを使用            |
| 状態通知         | 専用の区分なし             | `R`・`B` は着弾として記録しない    |
| チェックサム     | 形式だけを検査             | CSV にはない。RS-232C では値も照合 |
| 着弾音           | 変換成功した着弾ごと       | 変換成功した着弾ごと               |

BPT-216 はどちらの機器 ID でも、CSV の `T` 行と RS-232C の `P` 行を着弾候補として受理します。接続速度は使用するインターフェースに合わせてください。

未完行は次の受信まで保持します。1 行が 4096 バイトを超えた場合は、その行の終端まで破棄して次の行から再開します。非 ASCII、不正な得点精度、非整数座標、不正なチェックサムは着弾として通知しません。
