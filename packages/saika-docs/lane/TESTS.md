# Lane 操作確認シナリオ

[Lane 操作ガイド](./README.md)

[製品仕様](./SPEC.md) に沿って、設定・接続・記録・進行を確認する代表的な手順です。実機での確認状況は機器ごとの仕様を参照してください。検証用のデータと競技を使い、既存の記録は先に [バックアップ](./README.md#設定と記録を保存する) してください。

## 設定と接続

| 操作・条件                                | 期待する結果                                           |
| ----------------------------------------- | ------------------------------------------------------ |
| 保存データのない環境で起動                | 射座番号1、BR60S、音量50で起動。MQTT は無効            |
| General で射座番号3と音量を保存し、再起動 | 保存した値が表示される。標的への接続経験がなくても保持 |
| 射座番号を7へ変更して保存し、再起動       | 最新の7を使用                                          |
| Target で競技種別を選択                   | 新しい競技が始まり、種目と試射・本射の状態を表示       |
| 対応機器へ接続し、アプリを再起動          | メーカー・装置・ポートを復元し、接続を試行             |
| 使用できないポートへの接続を試行          | Connection タブにエラー。接続済みとは表示しない        |
| MQTT だけを接続                           | MQTT 接続と標的接続を別々に表示                        |

接続検証には実機または対応する検証用入力が必要です。機器ごとの受入条件は [対応機器](./SPEC.md#動作環境と対応機器) を参照してください。

## 記録と進行

| 操作・条件                                                                | 期待する結果                                                                             |
| ------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| 試射を記録し、Match の確認を確定する                                      | 試射を終了し、本射用の記録へ切り替わる。試射を本射合計へ加算しない                       |
| 以前のシリーズだけに着弾がある状態で Preparation を操作                   | 確認が開く。確定すると元のセッションを終了済みとして保存し、新しいセッションへ切り替わる |
| 開始待ち、またはセッションに着弾がない状態で Preparation を操作           | 確認せず実行する                                                                         |
| 着弾のない試射から Match へ進む、または次シリーズを開始                   | 確認せず実行する                                                                         |
| 競技の進行を使わず、着弾のある現在のシリーズで Preparation / Match を操作 | 確認が開く。現在のシリーズが空なら過去の着弾があっても確認しない                         |
| ボタンとテンキー `1` / `2` から確認を開く                                 | 同じ確認を表示し、Enter、テンキーの Enter、Confirm で一度だけ実行する                    |
| 確認中に Esc、ほかのキー、Cancel、閉じるボタン、ダイアログの外側を操作    | 実行せず閉じる。取消しのキーで進行・印刷・表示・設定の操作は動かない                     |
| 確認中にテンキー `1` / `2` を再度押す、またはキーを長押し                 | 押し直しは取消し。長押しの繰り返しは確定も取消しもしない                                 |
| Enter の長押しで確定後、元のボタンにフォーカスが戻る                      | キーを離すまで操作を繰り返さない。離して押し直すと通常の操作を受け付ける                 |
| 確認を開いて5秒間回答しない                                               | 実行せず閉じる                                                                           |
| 確認中に着弾、続いてシリーズ完了などの状態変更                            | 着弾は通常どおり表示。競技 ID・セッション ID・進行状態が変われば実行せず閉じる           |
| シリーズの上限射数まで記録                                                | 完了状態を表示。Advance、Match で次へ進む                                                |
| 同じステージの次シリーズへ進む                                            | ステージ全体の持ち時間は継続                                                             |
| 9発以上の着弾を記録                                                       | 標的上の表示は直近8発。古い記録も得点・印刷の対象として残る                              |
| 入力欄でテンキーを使う                                                    | 入力を受け付け、競技操作のショートカットを実行しない                                     |
| 現在のセッションを印刷                                                    | 本射があれば本射のみ、なければ現在の全着弾。個票の射数・得点が記録と一致                 |
| タイマーなしの試射を21発記録して印刷                                      | 第1・第2シリーズに各10発、第3シリーズに1発。各欄の合計・標的図も一致                     |
| Printing でプリンターと設定を保存し再起動                                 | 設定が復元され、Print とテンキー `9` でダイアログを開かず指定先へ送信                    |
| 出力先を Preview に戻す                                                   | 印刷画面を開き、Print から OS の印刷ダイアログを使える                                   |
| 保存先のプリンターを OS から削除して印刷                                  | エラーを表示し、別のプリンターへ送信しない                                               |
| 印刷中に Print とテンキー `9` を連続操作                                  | 処理中の送信が重複しない                                                                 |

### 三姿勢の標的モード

| 操作・条件                                                              | 期待する結果                                                                                                                                                                             |
| ----------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 50m・300m の予選・Elimination、三姿勢決勝の対象シリーズ                 | Sighting / Match を表示。単独・Director 参加中ともボタンとテンキー `1` / `2` で確認なく切り替わる                                                                                        |
| 対象8種目で伏射の対象シリーズへ入り、切り替えずに本射モードの着弾を受信 | 無効弾1件と Sighting へのリセット。射順・得点・射数・進行・時計は増えない                                                                                                                |
| 予選の立射の最初のシリーズで切り替えを忘れる                            | 前の伏射の無効弾として扱う。決勝の立射への試射専用区間は従来どおり                                                                                                                       |
| 最初の切り替え前に `2`、次に試射なしで `1` → `2`                        | 最初の `2` は無効。`1` 後の `2` は有効で最初の本射を記録できる                                                                                                                           |
| MT201 の Sighting 報告による試射後に `2`                                | 本射を許可し、切り替え忘れとして無効にしない                                                                                                                                             |
| 膝射の最終弾と複数の本射モードのフレームを続けて受信                    | 膝射の進行保存後に無効弾1件、残りは試射。伏射の本射枠を消費しない                                                                                                                        |
| 無効弾の直後に再起動                                                    | 起動復元と履歴照会を通して Sighting の選択と無効弾の行を復元し、切り替え済みを維持                                                                                                       |
| 役員の試射許可から本射へ再開                                            | `2` まで Sighting を維持。`2` 後の本射を無効にしない                                                                                                                                     |
| `1` の後、試射を撃たずに予備射座へ移動                                  | 移動先の Match は無効。移動先で `1` から選び直す                                                                                                                                         |
| 無効弾と続く試射の表示・配信                                            | 無効弾は射順「—」と規則を表示。同じシリーズの試射にも「Reported mode」を表示し、MQTT 得点と汎用 Vista 合計は増えない                                                                     |
| リセットの保存に失敗して再接続・再起動                                  | 無効弾の結果は1件のまま。失敗を表示し、現在のシリーズでリセットを再試行                                                                                                                  |
| 無効弾を Director へ配信                                                | 資料を保持し、役員の確認記録まで成績公開を保留。決勝の減点を自動適用しない                                                                                                               |
| Sighting を選んで着弾を記録                                             | モード表示と強調が Sighting。本射の射数・合計・シリーズ点・平均は増えない                                                                                                                |
| Match を選び、最初の本射を記録                                          | Sighting が無効になり理由を表示。`1` は再開始・確認・切り替えを実行しない                                                                                                                |
| 本射記録後に Sighting モードを報告                                      | Match として記録する                                                                                                                                                                     |
| 決勝の立射への姿勢変更・試射区間                                        | Sighting のみ選択可能。Match は無効で理由を表示                                                                                                                                          |
| 中断中の試射を役員が許可                                                | 端末・Lane・Vista が Sighting。再起動時の通常時計は停止し、再開許可を待つ。追加試射の実行中は両モードボタンと `1` / `2` を無効化。通常の PAUSED / 再起動停止ではシリーズの選択規則に従う |
| モード照会の失敗・古い応答の破棄後に `1` / `2` またはボタンを押す       | 再照会だけ実行し、再開始・確認・モード変更はしない。取得後の再操作で選択可能                                                                                                             |
| 選択、再選択、時計更新、再接続                                          | セッション・進行位置・射数・得点・共通時計を維持。時計更新と再接続では選択を保持                                                                                                         |
| 自動シリーズ移行、終了、時間満了、巻き戻し                              | 以前の選択を解除し、次の対象シリーズの表示を取得                                                                                                                                         |
| 進行・着弾通知後に古い照会応答が到着                                    | 新しい表示を維持                                                                                                                                                                         |
| 予備射座へ移動                                                          | 選択を解除し、通常の ATHLETE 着弾による観測を端末・表示に復元。必要なモードは移動先で再選択                                                                                              |

無効弾のないシリーズや練習では報告モードを表示しません。無効弾の装置点は整数点・小数点の採点方式に従い、リセット通知は次の選択または進行で消えます。これらも自動テストで検査します。

8種目の対象境界、連続受信、移動・再起動、無効弾と試射の表示、Director の資料保持と公開保留を自動テストで検査します。集約の選択寿命・本射開始後の制限、コマンドの配置照合、装置送信経路、画面操作・表示、MQTT の既存形式も検査します。実標的への切り替え反映と再接続時の装置応答は未確認です。

### 再起動からの復元

| 操作・条件                                                    | 確認する結果                                                                         |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| 単独使用の本射中に終了し、同じ保存先で再起動                  | 競技・セッション ID、着弾、ステージ・シリーズ位置を維持。元の時計期限を使う          |
| 単独時計の期限を過ぎて再起動                                  | 通常の満了処理になり、時間が増えない                                                 |
| AR60 のシリーズ間に再起動                                     | 単独では元の時計を継続。Director 参加中は PAUSED                                     |
| Director 参加中の時計を再起動し、新規案件から Apply Lane STOP | 停止時の残り時間を引き継いで案件 ID を採用。採用前の resume は拒否                   |
| PAUSED / RESUME_PENDING で再起動                              | 同じ案件 ID の PAUSED。既存案件で再開可能                                            |
| 停止済み競技の参加状態を解除                                  | ローカル再開・種別変更は不可。Finish saved run の確認後、着弾を残して終了            |
| 古い参加先と active 競技が不一致                              | 復旧画面で停止。MQTT 経由で古い参加先を解除し、Retry で active 競技を単独復元        |
| 起動時の状態照会中に通知・着弾を受信                          | 再照会し、着弾 ID の重複や消失がない                                                 |
| MQTT 有効かつ Auto Connect 有効                               | 復元 READY 後だけ自動接続。手動 Connect との重複接続なし                             |
| 再起動後の初回 MQTT 接続                                      | PAUSED を含む状態・得点・割当と現在のセッションの着弾を再送。Director で重複加算なし |

最終シリーズ完了後の参加 Lane は停止案件を追加せず、Director の満了・終了を受けることを検査します。READY の Retry と Finish saved run が標的ポートを開き直さないことも確認します。未検証の残り時間の画面表示、読めない run の確認付き退避、未知の保存種別からの明示的な作成、ERROR 中の時計・取り込み・競技再送の停止を検査します。予選復旧射の再起動では復元した実行の取消しを確認します。異なる手動接続入力の待ち合わせと、初回再送の失敗表示・再試行も対象です。

同じ user-data で実プロセスを再起動する単独使用の E2E を自動検証に含みます。実機の物理動作と射場の安全確認は別途行います。

## Director との連携

[導入と接続](../GETTING_STARTED.md) を終え、Director に表示された射座番号と実際の射座を揃えて確認します。

| 操作・条件                                     | 期待する結果                                                                                 |
| ---------------------------------------------- | -------------------------------------------------------------------------------------------- |
| 参加照会中                                     | 進行ボタン・テンキー `1` / `2` / `3`・Target の種別選択が無効                                |
| 参加照会に失敗                                 | 操作は無効のまま「Director membership could not be loaded」を表示し、詳細をログへ記録        |
| Director の競技へ参加                          | 通常の進行ボタンのツールチップと読み上げ用の説明に理由を表示。対象シリーズのモード選択は可能 |
| 確認画面を開いた後に参加状態が変化             | 確認を取消し、確定操作をしても実行しない                                                     |
| 参加中に通信を切断、または競技を終了           | 参加状態と進行操作の無効を維持。ズーム・全画面・印刷・役員への連絡・ほかの設定は利用可能     |
| 参加中に離脱処理が失敗、続いて成功             | 失敗時は参加を維持し、成功後に単独操作へ戻る                                                 |
| 再接続時に参加復元が失敗                       | 参加状態を解除し、画面にも通知する                                                           |
| 古い参加照会の応答が新しい変更通知より後に到着 | 新しい参加状態を保持する                                                                     |
| 同じ版・競技種別で参加し、大会の射座割を反映   | 各 Lane の参加 ACK が done となり、選手割当が一致                                            |
| 記録中に MQTT を切断して再接続                 | ローカル記録は継続。最新状態と再送データを受けても Director で重複計上しない                 |
| 安全 STOP を実行                               | STOP / UNLOAD を表示し、開始操作を禁止。タイマー停止後の射撃データを通常採点から隔離         |
| 安全確認を記録して STOP を解除                 | 停止状態は解除されるが、タイマーは自動で再開しない                                           |
| 中断を記録し、停止・許可・再開を順に操作       | 許可された時間とモードで再開し、各 Lane の ACK と状態が一致                                  |
| 競技を終了し、大会成績を保存                   | 保存先の選手・射群・射数・得点が一致してから離脱・保持データ消去が完了                       |

タイムアウト時は、Lane の実際の状態を確認してから再試行します。自動検査の対象は [Lane のテスト](../../saika-lane/tests/) と [Director のテスト](../../saika-director/tests/) を参照してください。

参加状態の保存・通知、照会と変更通知の順序、照会失敗、ローカル操作の無効化と確認の取消しは自動テストの対象です。実機・ブローカーを使った参加から離脱までの確認は別途必要です。

直接印刷の自動テストは、設定の保存・復元、送信オプション、描画待機、失敗・タイムアウトを対象とします。実プリンターでの用紙・カラー・両面の出力結果は未確認です。利用する OS とドライバーで確認してください。
