# Lane 操作確認シナリオ

[Lane 操作ガイド](./README.md)

[製品仕様](./SPEC.md) を確認するための代表的なシナリオです。全機能のテスト一覧や、実機検証済みの証明ではありません。検証用のデータと競技を使い、既存の記録を残す場合は先に [バックアップ](./README.md#設定と記録を保存する) を行ってください。

## 設定と接続

| 操作・条件                                | 期待する結果                                           |
| ----------------------------------------- | ------------------------------------------------------ |
| 保存データのない環境で起動                | 射座番号1、BR60S、音量50で起動。MQTT は無効            |
| General で射座番号3と音量を保存し、再起動 | 保存した値が表示される。標的への接続経験がなくても保持 |
| 射座番号を7へ変更して保存し、再起動       | 最新の7を使用                                          |
| Target で競技種別を選択                   | 新しい競技が始まり、種目と試射・本射の状態を表示       |
| 対応機器へ接続し、アプリを再起動          | メーカー・装置・ポートを復元し、接続を試行             |
| 使用できないポートへの接続を試行          | Connection タブにエラー。接続済みとは表示しない        |
| MQTT だけを接続                           | MQTT 接続と標的接続を別々に表示                        |

接続検証には実機または対応する検証用入力が必要です。機器ごとの受入条件は [対応機器](./SPEC.md#動作環境と対応機器) を参照してください。

## 記録と進行

| 操作・条件                                | 期待する結果                                                             |
| ----------------------------------------- | ------------------------------------------------------------------------ |
| 試射を記録して Match へ進む               | 本射用の記録へ切り替わり、試射を本射合計へ加算しない                     |
| シリーズの上限射数まで記録                | 完了状態を表示。Advance、Match で次へ進む                                |
| 同じステージの次シリーズへ進む            | ステージ全体の持ち時間は継続                                             |
| 9発以上の着弾を記録                       | 標的上の表示は直近8発。古い記録も得点・印刷の対象として残る              |
| 入力欄でテンキーを使う                    | 入力を受け付け、競技操作のショートカットを実行しない                     |
| 現在のセッションを印刷                    | 本射があれば本射のみ、なければ現在の全着弾。個票の射数・得点が記録と一致 |
| Printing でプリンターと設定を保存し再起動 | 設定が復元され、Print とテンキー `9` でダイアログを開かず指定先へ送信    |
| 出力先を Preview に戻す                   | 印刷画面を開き、Print から OS の印刷ダイアログを使える                   |
| 保存先のプリンターを OS から削除して印刷  | エラーを表示し、別のプリンターへ送信しない                               |
| 印刷中に Print とテンキー `9` を連続操作  | 処理中の送信が重複しない                                                 |

## Director との連携

[導入と接続](../GETTING_STARTED.md) を終え、Director に表示された射座番号と実際の射座を揃えて確認します。

| 操作・条件                                   | 期待する結果                                                                         |
| -------------------------------------------- | ------------------------------------------------------------------------------------ |
| 同じ版・競技種別で参加し、大会の射座割を反映 | 各 Lane の参加 ACK が done となり、選手割当が一致                                    |
| 記録中に MQTT を切断して再接続               | ローカル記録は継続。最新状態と再送データを受けても Director で重複計上しない         |
| 安全 STOP を実行                             | STOP / UNLOAD を表示し、開始操作を禁止。タイマー停止後の射撃データを通常採点から隔離 |
| 明示安全確認で STOP を解除                   | 停止状態は解除されるが、タイマーは勝手に再開しない                                   |
| 中断を記録し、停止・許可・再開を順に操作     | 許可された時間とモードで再開し、各 Lane の ACK と状態が一致                          |
| 競技を終了し、大会成績を保存                 | 保存先の選手・射群・射数・得点が一致してから離脱・保持データ消去が完了               |

タイムアウト時は、Lane の実際の状態を確認してから再試行します。自動検査の対象は [Lane のテスト](../../saika-lane/tests/) と [Director のテスト](../../saika-director/tests/) を参照してください。

直接印刷の自動テストは、設定の保存・復元、送信オプション、描画待機、失敗・タイムアウトを対象とします。実プリンターでの用紙・カラー・両面の出力結果は未確認です。利用する OS とドライバーで確認してください。
