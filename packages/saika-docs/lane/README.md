# Lane 操作ガイド

[マニュアルの入口](../README.md) / Lane 操作ガイド

射座の PC で着弾位置と得点を確認するためのガイドです。
接続設定は [導入と接続](../GETTING_STARTED.md)、大会を一括進行する場合は [Director 操作ガイド](../director/README.md) も参照してください。

## 起動と準備

1. 標的装置を PC に接続し、Saika Lane を起動する。
2. 左下の歯車「Settings」→「General」を開く。
3. 「Lane Number」に射座番号を入力する。「Shot Sound Volume」で音量を調整し、スピーカーボタン「Test sound」で確認して「Save」を押す。
4. 単独で使う場合は「Settings」→「Target」で競技種別を選ぶ。選択すると、その場で新しい競技が始まる。種目名と試射・本射の表示を確認してください。

設定項目が画面の高さに収まらない場合は、タブの下の内容を上下にスクロールしてください。下部の設定項目や保存ボタンまで移動できます。タイトル、閉じるボタン、タブはスクロール中も表示されます。

選択できる種目、射数、時間は [競技種別定義](../common/COMPETITION_TYPES.md) を参照してください。

保存した射座番号、音量、競技種別、接続設定は次回起動時にも使われます。
前回の標的装置へ自動接続を試みるため、起動後に接続状態を確認してください。

## 標的装置へ接続する

1. 「Settings」→「Connection」を開く。
2. 「Serial Port」で接続先を選ぶ。見つからなければ右の更新ボタンで再検索する。
3. 「Target Manufacturer」と「Target Device」で、使用するメーカーと装置を選ぶ。
4. 「Connect」を押す。接続できるとボタンが「Disconnect」に変わる。
5. 設定を閉じ、画面右下の接続アイコンにマウスを重ねて「Target Device: Connected」を確認する。

このアイコンは標的装置の接続状態です。Director との通信状態は「Settings」→「MQTT」の「Status」で確認します。機器ごとの実装状況は [Lane 製品仕様](./SPEC.md) を参照してください。

## 試射から本射へ進む（単独使用）

試射を含む競技では、左側の状態表示とボタンを確認して進めます。
左端のボタン名は、マウスを重ねると表示されます。

1. 「Preparation」と表示されていれば試射中である。開始待ちの場合は左端の「Preparation」を押す。
2. 試射を終えて本射を始めるときは「Match」を押す。
3. 「Series Complete」になったら「Advance」を押す。
4. 「Next Series」または「Next Stage」になったら「Match」を押して開始する。
5. 最終シリーズの後に「Advance」を押し、「Finished」を確認する。

試射を終了して待機したいときは 「End Preparation」 を押します。
その後は 「Advance」 → 「Match」 の順で本射へ進みます。

「Preparation」は射撃中やシリーズの完了・切り替え待ちに押すと、新しい記録単位（セッション）へ切り替わります。射撃中は開始待ちに戻り、「Series Complete」「Next Series」「Next Stage」では先頭のステージを開始します。一時停止や次シリーズへの移動には使わないでください。記録を残す場合は、切り替え前に [印刷](#記録を印刷する) します。新しい競技を始めるときは「Settings」→「Target」から競技種別を選びます。

## 表示を調整する

- 左側には種目、射座番号、進行状態、合計点、直近10発、シリーズ得点、平均点を表示する。競技に応じて残り時間とシリーズの進行状況も表示する。
- 標的には直近8発を表示する。古い着弾が標的上から消えても、記録が削除されたわけではない。
- 「Zoom」は自動 → 8点圏 → 6点圏 → 4点圏 → 標的全体の順に切り替わる。自動表示へ直接戻すにはテンキーの `5` を押す。

| キー               | 操作                                        |
| ------------------ | ------------------------------------------- |
| テンキー `1` / `2` | Preparation / Match                         |
| テンキー `3`       | End Preparation / Advance（進行状態による） |
| テンキー `5` / `6` | 自動ズームへ戻す / ズームを順に切り替える   |
| テンキー `9`       | 保存した設定で印刷（未設定時は印刷画面）    |
| テンキー `.`       | Settings を開閉する                         |
| `F11`              | 全画面表示を切り替える                      |
| `Esc`              | Settings を閉じる                           |

数字キーはテンキー側を使います。入力欄を編集中はテンキーの操作ショートカットは働きません。

## 記録を印刷する

プリンターを事前に設定しておくと、ボタンを押すだけで印刷できます。

1. OS にプリンターを追加し、「Settings」→「Printing」を開く。
2. 「Printer」で出力先を選び、用紙（A4・A5・Letter・Legal）、向き、部数（1〜99）、カラー、片面・両面を設定する。
3. 「Save Printing Settings」で保存する。設定は再起動後も保持される。
4. 左下の「Print」またはテンキーの `9` を押す。現在のセッションの個票を、プレビューや OS の印刷設定ダイアログを開かずに送信する。

一覧が古い場合は「Refresh Printers」を押します。保存したプリンターが見つからない場合や印刷の受付に失敗した場合は、メイン画面にエラーが表示されます。「Printing Settings」から出力先を確認してください。処理中は重複して送信しません。タイムアウト後に再試行する場合は、先に OS の印刷キューを確認します。

印刷内容のプレビュー、PDF 保存、ドライバー固有の設定を使う場合は、「Printer」で「Preview (choose printer each time)」を選んで保存します。初期状態もこの方式です。

1. 「Print」またはテンキーの `9` で印刷画面を開く。
2. 種目、射座番号、得点を確認し、印刷画面の「Print」を押す。
3. OS の印刷ダイアログで出力先を選ぶ。PDF 保存が選べる環境では、ファイルとして保存できる。出力後は「Close」で戻る。

用紙・カラー・両面の対応状況はプリンターに依存します。初回は出力結果と改ページを確認してください。印刷処理の完了はジョブの受付を表し、紙への出力完了はプリンター側で確認します。

本射の記録があれば本射を印刷し、本射がまだなければ試射を含む現在の記録を印刷します。
試射から本射への移行や競技のやり直しでセッションが切り替わるため、残したい記録は切り替え前に確認してください。

大会の順位表は [Director の成績一覧](../director/RESULTS.md#成績一覧を印刷する) から印刷します。Lane の個票に表示する項目と制約は [帳票仕様](../common/PRINT_SPEC.md#lane-の個票scoresheet) を参照してください。

## Director と連携して使う

競技の開始、試射・本射の切り替え、中断・再開は Director 担当者の指示に従います。
連携中に 「Target」 の競技種別や 「Preparation」、「Match」、「Advance」 を独自に操作しないでください。

- 「STOP」：射撃を止め、射場役員の指示を待つ。
- 「STOP / UNLOAD」：射場役員の指示に従って射撃停止・除弾する。Lane 画面に解除ボタンはない。
- 「SIGHTING」：中断からの復旧で試射が許可された状態。本射再開は担当者の指示を待つ。

### 役員へ連絡し、対応後に通知を解除する

困ったときは左側の操作メニューで、ベルの「Range Officer」を押します。申告の種類を選び、必要に応じて詳細や観察内容を入力します。

- 「Call RO」：理由を選び、「Call Range Officer」で射場役員を呼ぶ。
- 「Declare malfunction」：Qualification（予選）の銃器故障の疑いを「Declare possible malfunction」で申告する。
- 「EST complaint」：得点表示、未表示の着弾、標的装置などの問題の種類を選び、「Raise EST complaint」で申告する。

申告中はベルに小さな琥珀色の印が付きます。「Range Officer」を開くと、該当する項目で「Active」を確認できます。標的上には申告ボタンを表示しません。銃器故障・EST の申告には、進行中の競技と選手割当が必要です。送信エラーが出た場合は表示内容を確認し、役員に直接伝えてください。

これらの申告はタイマーを止めず、得点の修正や判定も行いません。MQTT 切断中は Lane に保存され、再接続後に送信されるため、急ぎの連絡は直接役員に伝えてください。

Director 担当者は、銃器故障の申告を [予選の銃器故障の記録](../director/OPERATIONS.md#予選の銃器故障を記録する)、EST の申告を [標的調査の手順](../director/OPERATIONS.md#調査資料を残す) で扱います。

役員が対応した後は、「Range Officer」から申告中の項目を開き直します。役員呼出は「Clear request」、銃器故障・EST は「Clear after official acknowledgement」を押して解除します。すべての申告を解除すると、ベルの印が消えます。Director の案件に必要な記録を残してから解除してください。通知の解除では、Director の案件を閉じたり資料保全を解除したりしません。

## 着弾時刻の判定を設定する

25m などの標的時間制御で、受信遅延や時計の不確かさを考慮する設定です。競技を終了してから変更します。手入力は [計時設定](./SPEC.md#計時測定データとプロファイル)、測定データを使う場合は [プロファイルの作成・適用手順](./SPEC.md#測定プロファイルを作成して適用する) に従ってください。プロファイルの解析・保存後には、設定への適用も必要です。

## よくある困り事

| 状況                       | 確認すること                                                                                   |
| -------------------------- | ---------------------------------------------------------------------------------------------- |
| ポートが見つからない       | 装置の電源とケーブルを確認し、「Connection」 でポート一覧を更新します。                        |
| 接続に失敗する             | 「Connection」 のエラーを確認し、ポート・メーカー・装置の選択を見直します。                    |
| 接続済みなのに着弾が出ない | 種目と装置が合っているか、試射・本射が開始されているかを確認します。大会中は役員へ連絡します。 |
| ボタンを押せない           | 現在の進行状態では使えない操作です。状態表示と上記の操作順を確認します。                       |
| 音が出ない                 | 「General」 の 「Test sound」、音量、PC の音量と出力先を確認します。                           |
| Director に届かない        | 「MQTT」 の 「Status」 と通信設定を確認し、Director 担当者へ連絡します。                       |

### ログを確認する

画面右下の虫のアイコン「Open Debug Panel」でログを開きます。発生時刻、レベル、メッセージを確認し、流れて読みにくい場合は「Auto-scroll」をオフにします。「Clear」は画面のログ表示を消す操作です。

配布版のログファイルは、[ユーザーデータフォルダー](./SPEC.md#データの保存場所) 内の `logs/combined.log` と `logs/error.log` にあります。過去の記録を確認する場合やアプリが起動しない場合は、これらのファイルを確認してください。問い合わせに添える情報は [導入ガイド](../GETTING_STARTED.md#問い合わせに必要な情報) にまとめています。

## 設定と記録を保存する

過去のセッションを選んで開く履歴画面はありません。個票を残す手順は [記録を印刷する](#記録を印刷する) を参照してください。

更新や PC の移行に備えてデータを保管する場合は、次の順でコピーします。

1. 「Settings」→「JSON」で `settings.json` の保存場所を確認する。
2. 競技を終了し、Lane を閉じる。
3. `settings.json` を含むユーザーデータフォルダー全体を、保存日が分かる別の場所へコピーする。

フォルダーには設定、データベース、ログなどが入ります。設定ファイルだけでは着弾履歴を保存できません。既定の保存場所とファイルの役割は [データストレージ](./SPEC.md#データの保存場所) を参照してください。同じ設定を複数の Lane へ直接コピーすると通信上の ID も重複し得るため、各端末の接続設定は個別に行います。

### 保存したデータを戻す

同じ端末への復元、または元の端末を置き換える移行を対象にします。複数の射座への設定配布には使いません。

1. バックアップを作成した版の Lane を用意する。移行先では一度起動して「JSON」で保存場所を確認し、閉じる。
2. 元の端末と移行先の Lane を終了する。移行先に既存データがあれば、そのフォルダーも別の場所に保管する。
3. 移行先のユーザーデータフォルダーを、保存済みのフォルダー全体で置き換える。新旧のファイルを混在させない。
4. Lane を起動し、版、射座番号、競技種別、標的装置、ポート、MQTT 設定を確認する。移行先でポート名が変わった場合は選び直す。

起動できなければ Lane を閉じ、置き換え前のフォルダーへ戻してログを確認します。新しい版のデータを古いアプリで直接開くことは避けてください。

設定値や状態の詳細は [Lane 製品仕様](./SPEC.md)、導入後の確認例は [操作確認シナリオ](./TESTS.md) を参照してください。
