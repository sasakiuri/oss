NotoSansJP-Docs.woff2: static weight 400 subset of the above font,
created with fontTools 4.57.0 for the documentation and shared UI character set.
Next.js preloads this subset. Uncovered glyphs use the complete Fontsource family.
The complete font is retained for PDF generation.
Regenerate after content:generate with scripts/subset-font.py in an isolated
Python environment containing fonttools[woff]==4.57.0. Normal npm builds use the
checked-in subset and need no Python toolchain.
