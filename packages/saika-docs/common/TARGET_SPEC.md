# 標的・採点データ

[文書一覧](../INDEX.md)

Saika Lane が描画と座標採点に使う標的面、採点ゲージ、インナー 10 の定義を説明します。数値は現行実装の値です。公式規則の確認先は [参照元](../SOURCES.md) にまとめています。

## 得点の扱い

Lane は装置得点を優先し、装置得点がない場合に座標から計算した得点を使います。装置得点と計算値に差があれば診断情報を残します。差だけを理由に装置得点を上書きしません。

- `deviceScore` は装置が通知した得点。
- `calculatedScore` は選択した標的面と採点ゲージによる座標計算値。
- 採用する得点は、整数点採点なら小数部分を切り捨て、小数点採点なら小数第 1 位まで保持する。
- 保存・通信上の得点は 0.1 点単位の整数。例えば `109` は 10.9 点、`100` は 10.0 点。

競技種別による採点方法やヒット数集計は [競技種別定義](./COMPETITION_TYPES.md) を参照してください。機器の受信値から座標への変換は、各 [受信互換仕様](../INDEX.md#外部仕様連携仕様) に記載しています。

## 標的面と採点ゲージ

標的面はリング線の半径を定義し、採点ゲージは着弾中心からリング線への接触判定に使います。同じ標的面でも競技種別によって採点ゲージが変わります。Rule Pack が指定する場合はその値を使い、指定がない場合は標的面の既定値を使います。

| 採点ゲージ ID                   | 直径（mm） | 用途                                         |
| ------------------------------- | ---------: | -------------------------------------------- |
| `JRSF_BEAM_RIFLE_VIRTUAL_6_00`  |       6.00 | ビームライフルの仮想弾                       |
| `JRSF_BEAM_PISTOL_VIRTUAL_4_50` |       4.50 | ビームピストルの仮想弾                       |
| `ISSF_AIR_4_50_2026`            |       4.50 | 10m エアライフル・エアピストル               |
| `ISSF_SMALLBORE_5_60_2026`      |       5.60 | 50m ライフル・50m ピストル・25m リムファイア |
| `ISSF_CENTER_FIRE_9_65_2026`    |       9.65 | 25m センターファイアピストル                 |
| `ISSF_RIFLE_8_00_2026`          |       8.00 | 300m ライフル                                |

ゲージの直径は、すべての機器で実弾やビームの直径を表すわけではありません。採点時の標的面とゲージの ID は各射の記録に保持します。

## 座標からの得点計算

着弾中心と標的中心との距離を `d`、採点ゲージ半径を `g` とします。いずれも mm 単位です。整数点の中心距離上限は `リング線の半径 + g` です。境界上の着弾は内側の得点に含めます。

小数点採点では、ゲージ補正後の整数点の帯を 10 等分します。

```text
内縁 = 10 点帯では 0、それ以外は一つ内側のリング線半径 + g
外縁 = 対象リング線の半径 + g
ステップ幅 = (外縁 - 内縁) / 10
N.k 点の中心距離上限 = 内縁 + (10 - k) × ステップ幅
```

`N` は整数点、`k` は 0〜9 です。上限を小数第 4 位に丸め、高得点から順に `d <= 上限` を判定します。どの上限にも入らなければ 0 点です。座標のないミスも 0 点とし、インナー 10 は付けません。

例えば AR の 10 点帯では `g = 2.25`、外縁は `0.25 + 2.25 = 2.50`、ステップ幅は `0.25` です。

| 中心距離（mm） | 座標計算値 |
| -------------- | ---------: |
| 0〜0.25        |       10.9 |
| 0.25 超〜0.50  |       10.8 |
| 2.25 超〜2.50  |       10.0 |
| 2.50 超〜2.75  |        9.9 |

## インナー 10

インナー 10 は得点値だけで判定せず、着弾中心までの距離で判定します。境界上も含めます。固定の中心距離を使う標的と、専用リング線の半径にゲージ半径を加える標的があります。

| 標的                   | 判定方法 | 既定ゲージでの中心距離上限（mm） |
| ---------------------- | -------- | -------------------------------: |
| JRSF_BR_10M            | 固定     |                             2.25 |
| JRSF_BP_10M            | 固定     |                             5.00 |
| ISSF_AR_10M            | 固定     |                             2.00 |
| ISSF_AP_10M            | 固定     |                             4.75 |
| ISSF_SB_50M            | 2.5 + g  |                             5.30 |
| 300m ライフル          | 25 + g   |                            29.00 |
| 50m ピストル・25m 精密 | 12.5 + g |                            15.30 |
| 25m 速射               | 25 + g   |                            27.80 |

センターファイアでは `g = 4.825` のため、精密は 17.325 mm、速射は 29.825 mm です。

### JRSF_BP_10M（10m ビームピストル標的）

BP と AP はリング線と既定ゲージ直径が共通ですが、インナー 10 の中心距離上限は異なります。例えば中心から 5.00 mm の着弾は BP ではインナー 10 に入り、AP では入りません。`BP60` の成績は整数点採点です。
