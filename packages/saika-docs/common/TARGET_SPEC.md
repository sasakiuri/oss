# 標的仕様 (Target Specifications)

## 概要

本ドキュメントは、Saika Lane が描画と採点に使用する標的データを説明する。規則本文や公式図版の転載ではない。

リング半径の値は [`targetRadii.ts`](../../saika-lane/src/renderer/presentation/components/target/targetRadii.ts)（描画用）および [`TargetDesign.ts`](../../saika-lane/src/main/modules/target/domain/TargetDesign.ts)（採点用）の実装と対応する。

> 数値は実装確認用であり、公式性や現行規則との一致を保証しません。競技で使用する場合は [ISSF・JRSFの一次情報](../SOURCES.md) と照合してください。

## スコアリング方式

| 方式       | 説明                             |
| ---------- | -------------------------------- |
| outer-edge | 弾の外縁がリング線に触れれば得点 |

**判定式**: `distance <= ring.radius`

全種目で outer-edge スコアリングを採用する。各種目の `shotRadius`（弾半径）はリング定義生成時に帯境界に組み込まれており、`calculateScore` では弾中心からの距離のみで判定する。

## 小数点スコアリング（Decimal Scoring）

各整数点圏の帯（隣接する2本のリング線の間の領域）を10等分し、小数点スコアを導出する。内側（中心に近い側）から N.9, N.8, …, N.0 の順にスコアを割り当てる。各帯のステップ幅は種目・帯幅に応じて異なる。

### 計算式

| 項目       | 式                                               |
| ---------- | ------------------------------------------------ |
| 内縁       | Band 0: 0, Band N (N≥1): radii[N−1] + shotRadius |
| 外縁       | radii[N] + shotRadius                            |
| ステップ   | (外縁 − 内縁) ÷ 10                               |
| N.k の半径 | 内縁 + (10 − k) × ステップ                       |

### 変数の定義

- **band**: 整数点圏のインデックス（0 = 10点圏、9 = 1点圏）
- **k**: 小数点以下の値（整数、0〜9）
  - k = 9: N.9（最高小数スコア、内縁に近い）
  - k = 0: N.0（最低小数スコア、外縁に近い）

### 例: ISSF_AR_10M の10点帯（shotRadius=2.25mm）

- 内縁: 0mm（Band 0）
- 外縁: 0.25mm + 2.25mm = 2.50mm
- ステップ: 2.50 ÷ 10 = 0.25mm

| スコア | 判定半径 (mm) | 計算                |
| ------ | ------------- | ------------------- |
| 10.9   | 0.25          | 0 + (10 − 9) × 0.25 |
| 10.8   | 0.50          | 0 + (10 − 8) × 0.25 |
| 10.7   | 0.75          | 0 + (10 − 7) × 0.25 |
| 10.6   | 1.00          | 0 + (10 − 6) × 0.25 |
| 10.5   | 1.25          | 0 + (10 − 5) × 0.25 |
| 10.4   | 1.50          | 0 + (10 − 4) × 0.25 |
| 10.3   | 1.75          | 0 + (10 − 3) × 0.25 |
| 10.2   | 2.00          | 0 + (10 − 2) × 0.25 |
| 10.1   | 2.25          | 0 + (10 − 1) × 0.25 |
| 10.0   | 2.50          | 0 + (10 − 0) × 0.25 |

### スコア範囲

- **最高スコア**: 10.9
- **最低スコア**: 1.0
- **全リング外**: 0.0（ミス）

#### DISAG RedDot（ライフル）の座標・採点データ

DISAG RedDotをライフル標的として接続する場合は、`ISSF_AR_10M` に対応付ける。以下は、メーカーの
公開資料と2026-08-08の独立実機確認に基づくSaika側のデータ規約である。RS-232のフレーム形式や
制御手順は、この節の対象外とする。実装に必要な通信仕様は
[DISAG RedDot受信互換・実装仕様](../lane/devices/disag/reddot/README.md) を参照する。

| 項目            | 技術仕様                            |
| --------------- | ----------------------------------- |
| 原点            | 標的中心                            |
| X軸             | 右方向が正、左方向が負              |
| Y軸             | 上方向が正、下方向が負              |
| X/Yの1単位      | 0.01mm                              |
| 中心距離の1単位 | 0.01mm                              |
| 仮想弾径        | 4.5mm                               |
| 仮想弾半径      | 2.25mm                              |
| Saika標的コード | `ISSF_AR_10M`                       |
| DISAG上の種別   | `LG`（Luftgewehr、10mエアライフル） |

座標と中心距離は次のようにmmへ正規化する。

```text
xMm = xRaw / 100
yMm = yRaw / 100
distanceMm = distanceRaw / 100
distanceMm ≈ sqrt(xMm² + yMm²)
```

X/Yは0.01mm刻みで表現される。中心距離に小数第1位まで含まれる場合、その表示分解能は0.001mmに
相当するが、これは装置の測定精度を意味しない。メーカー公開値の繰返し精度は±0.1mmである。

Canvasなど画面下方向が正の描画座標へ変換する場合は、Yだけを反転する。

```text
screenX = centerX + xMm * pixelsPerMm
screenY = centerY - yMm * pixelsPerMm
shotRadiusPx = 2.25 * pixelsPerMm
```

RedDotはレーザー標的であるため、4.5mmはレーザースポットの直径ではない。`ISSF_AR_10M` の
outer-edge採点と弾痕表示に使用する仮想的な弾径である。10点圏の中心距離上限は
`0.25 + 2.25 = 2.50mm`、9点圏の中心距離上限は `2.75 + 2.25 = 5.00mm` となり、小数点採点の
半径方向ステップは0.25mmとなる。

参照した一次情報は [参照元](../SOURCES.md) に記載する。
