# 帳票仕様

[文書一覧](../INDEX.md)

Lane と Director の帳票について、対象、表示項目、得点単位、制約を説明します。操作手順は [Lane の個票印刷](../lane/README.md#記録を印刷する) と [Director の成績一覧印刷](../director/RESULTS.md#成績一覧を印刷する)、結果の公表・保存は [成績・データ保管ガイド](../director/RESULTS.md) を参照してください。

## 出力の種類

| 出力             | アプリ   | 対象と内容                                   |
| ---------------- | -------- | -------------------------------------------- |
| ScoreSheet       | Lane     | 現在のセッションの得点、着弾、シリーズ明細   |
| ResultsListSheet | Director | 予選の順位、シリーズ得点、公表状態           |
| FinalResultSheet | Director | 決勝の累積点、脱落位置、順位確認の表示       |
| Results Book     | Director | 版を固定し、署名・認証を記録する大会成績冊子 |
| 運用記録・原資料 | Director | 抗議、中断・事故、独立バックアップなど       |

対象競技・出力経路によって表示項目が異なります。個別帳票を印刷する操作と、成績の確定・承認・公式公表は別です。

Director にも個票（ScoreSheet）の生成処理がありますが、現行の操作画面に起動ボタンはありません。対象は受信済みの Lane の本射データで、大会に保存した成績を読み出す帳票とは異なります。個票を残す場合は Lane の印刷機能を使います。

## 用紙・日付・得点単位

個票と成績一覧の基準用紙は A4縦、余白は10mm です。印刷時は画面の操作ボタンを非表示にします。画面上のプレビューとプリンタードライバーの結果は異なる場合があるため、出力前に用紙設定と改ページを確認してください。

個票・成績一覧に表示する日付は、印刷する PC のローカル日付です。大会開催日とは区別します。成績冊子は保存済みの版を出力し、個票・一覧とは別に管理します。

| データ                                                                        | 単位・表示                                  |
| ----------------------------------------------------------------------------- | ------------------------------------------- |
| Lane の `ScoreSheetDto.totalScore`、`seriesScores`、各射の `value`            | 0.1点を整数1として保持。表示時に10で割る    |
| Lane の `totalIntegerScore`、各射の `integerValue`                            | 各射の小数部分を切り捨てた整数点            |
| Director の `ScoreSheetDto`、`RankedResultDto`、`FinalRankedResultDto` の得点 | 点単位の数値。Lane の10倍表現として扱わない |
| 予選成績一覧                                                                  | 競技種別に応じて整数、または小数1桁         |
| 未発射・未設定                                                                | 空欄または `—`。記録された0点と区別         |

## Lane の個票（ScoreSheet）

### 目的とデータ選択

射座ごとの得点、着弾、シリーズ内訳を印刷する。Saika Lane の現行実装は次の順で対象ショットを
選択する。

1. 本射ショットが1発以上あれば、本射ショットだけを使う。
2. 本射開始前など、本射ショットがなければセッション内の全ショットを使う。
3. シリーズ番号の昇順にまとめ、各シリーズ内で1からショット番号を振り直す。

このフォールバックは試射内容の確認用であり、試射を公式記録に含める規則を意味しない。

### 得点と明細のデータ

`ScoreSheetDto`:

| フィールド        | 型                  | 単位・意味                         |
| ----------------- | ------------------- | ---------------------------------- |
| sessionId         | string              | セッション ID                      |
| laneNumber        | number              | 射座番号                           |
| relay             | number              | 射群番号。`0` は未設定             |
| playerName        | string              | 選手名。現行 Lane 単体では空文字   |
| affiliation       | string              | 所属。現行 Lane 単体では空文字     |
| allShots          | ScoreSheetShotDto[] | 印刷対象ショット                   |
| seriesScores      | number[]            | シリーズ合計。0.1点を整数1とする   |
| totalScore        | number              | 全ショット合計。0.1点を整数1とする |
| totalIntegerScore | number              | 各発を整数化してから合計した値     |
| disciplineName    | string?             | 種目表示名                         |
| discipline        | Discipline          | 標的描画に使用する種目 ID          |

`ScoreSheetShotDto`:

| フィールド   | 型             | 単位・意味                                 |
| ------------ | -------------- | ------------------------------------------ |
| shotNumber   | number         | シリーズ内の1始まり連番                    |
| value        | number         | 0.1点を整数1とする得点                     |
| integerValue | number         | `floor(value / 10)`                        |
| seriesNumber | number         | 1始まりのシリーズ番号                      |
| x            | number \| null | 標的中心基準の X 座標（mm）。ミスは `null` |
| y            | number \| null | 標的中心基準の Y 座標（mm）。ミスは `null` |

### レイアウト

帳票は次の独立した機能ブロックで構成する。

```text
┌──────────────────────────────────────────────────┐
│ 種目名                              印刷日付      │
│ Lane: 射群-射座                                  │
│ 選手名 — 所属                                    │
├─────────────────────────────┬────────────────────┤
│ Result / Series / 点数別集計 │ 全着弾の標的図     │
├─────────────────────────────┴────────────────────┤
│ Series 1  標的図  整数合計 (小数合計)  5×2発     │
│ Series 2  標的図  整数合計 (小数合計)  5×2発     │
│ …                                                │
└──────────────────────────────────────────────────┘
```

- ヘッダーは種目、射群・射座、選手、所属、印刷日を表示する。
- サマリーは小数点合計、整数合計、シリーズ合計、10点から0点までの発数を表示する。
- 全着弾の標的図には通しのショット番号を描画する。
- 各シリーズは標的図、合計、5列×2行の最大10発を表示する。
- 表示枠は最低6シリーズ分を確保する。7シリーズ目以降もデータがあれば表示し、7シリーズ目の前で
  改ページする。
- 得点がないシリーズ枠と未発射セルは `-` を表示する。

### 現行制約

Lane 単体では大会名、会場、選手名、所属、射群が入力データに接続されていません。日付・得点単位・印刷結果の注意点は、共通の [用紙・日付・得点単位](#用紙日付得点単位) を参照してください。

## Director の予選成績一覧

対象は種目全体または指定した射群です。成績保存時の順位を受け取り、印刷側で得点から順位を付け直しません。

| 表示項目 | 内容                                                           |
| -------- | -------------------------------------------------------------- |
| 見出し   | 種目名、指定時の射群、印刷日、Rule Pack                        |
| 選手     | 順位または参加区分、スタート番号、氏名、国コード、所属         |
| 得点     | 競技種別に応じたシリーズ列、合計、備考                         |
| 公表状態 | 下書き・暫定・公式などの状態。公表後に変更があれば要確認の表示 |
| 抗議受付 | 対象となる公表状態では受付終了時刻                             |

シリーズ列は競技種別から決まり、6列固定ではありません。DNS、DSQ などの区分では得点を表示しない場合があります。RPO、MQS、OOC なども通常の順位と区別します。登録情報や公表状態を修正した場合は、印刷画面を開き直して確認してください。

## Director の決勝成績一覧

種目名、印刷日とともに、選手の順位・氏名・所属・累積点・合計・備考を表示します。「Results」→「Print」から開く場合、大会名と会場は空欄です。失格区分と順位の再確認が必要な成績は、その状態を表示します。

現行の累積点レイアウトは、5発目・10発目と、12〜24発目の2発ごとの列です。脱落後の得点は `—`、脱落位置は `E18` などで示します。記録された順位で並べ、失格区分のある行は後ろに配置します。

### 現行の制約

- 混合団体決勝の「Results」には成績一覧の印刷ボタンがない。
- この固定レイアウトを、混合団体・三姿勢・25m を含む全決勝の発数構成に共通の様式として扱わない。
- 同点決定戦の表示部品はあるが、通常の成績一覧の印刷画面からは同点決定戦データを渡していない。
- 順位判断や同点処理の根拠は、Director の決勝記録と証拠資料も確認する。

## 成績冊子・運用記録との使い分け

| 目的                           | 出力と確認                                                             |
| ------------------------------ | ---------------------------------------------------------------------- |
| 大会成績冊子を配布             | Results Book で版を作成し、必要な署名・認証後に HTML・PDF・JSON を出力 |
| 裁定・調査の根拠を保管         | Evidence bundle を JSON で保存。印刷物だけに依存しない                 |
| 独立バックアップの原資料を確認 | 取り込んだ資料の「Print source」を使用                                 |
| 抗議・上訴書類を準備           | 運用記録の印刷と、対応する公式 PDF 原本への転記を使い分ける            |
| Director 全体を復元            | Database backup を使用。成績冊子や証拠 JSON では復元できない           |

具体的な前提と手順は [Director 成績・データ保管ガイド](../director/RESULTS.md#成績冊子と証拠資料を保存する) にまとめています。
