# 用語集

[文書一覧](../INDEX.md)

Lane と Director の画面やマニュアルで使う用語を説明します。競技種別ごとの射数・時間・採点方法は [競技種別定義](./COMPETITION_TYPES.md) を参照してください。

## 大会と競技の構造

| 用語       | 画面・コードの表記 | 意味                                                                             |
| ---------- | ------------------ | -------------------------------------------------------------------------------- |
| 大会       | Championship       | 日付、会場、種目、参加者、成績をまとめる単位です。                               |
| 種目       | Event              | 大会内の競技種別と参加者を管理する単位です。                                     |
| 射群       | Relay              | 射座割に従って同じ時間帯に射撃する選手の組です。                                 |
| 競技       | Competition        | Director が Lane の参加、選手割当、試射・本射を制御する単位です。                |
| 競技種別   | CompetitionType    | `BR60S`、`AR60` など、種目と進行方法を選ぶための識別子です。                     |
| ラウンド   | Round              | Elimination、Qualification、Final など、競技の区分です。                         |
| ステージ   | Stage              | 試射、本射、姿勢変更など、ラウンド内の進行区分です。                             |
| シリーズ   | Series             | ステージ内でまとめて扱う射撃の単位です。射数と時間は競技種別によって変わります。 |
| フェーズ   | Phase              | 開始待ち、射撃中、シリーズ完了など、現在の進行状態です。                         |
| セッション | Session            | Lane が着弾を保存する記録単位です。本射への移行やリセットで切り替わります。      |

本書では Qualification を「予選」、Final を「決勝」と表記します。Elimination は Qualification の前に参加者を絞るラウンドです。画面との対応を保つため、Elimination は英語表記を使います。決勝内の「Elimination Stage」は脱落が発生するステージで、別ラウンドの Elimination とは区別します。

## 射撃と得点

| 用語        | 画面・コードの表記     | 意味                                                                                 |
| ----------- | ---------------------- | ------------------------------------------------------------------------------------ |
| 試射        | Sighting / Preparation | 照準などを確認する射撃です。着弾は記録されますが、本射の合計点には加算されません。   |
| 準備時間    | Preparation            | 射撃前の準備に使う時間です。試射の可否は選択した競技と現在の指示に従います。         |
| 本射        | Match / Record         | 成績に使用する射撃です。画面の得点表示と、結果の確定・公表は別の状態です。           |
| 着弾        | Shot / POI             | 標的が検出した射撃データです。POI は着弾位置を指します。                             |
| 点数        | Score                  | 装置の値や着弾座標から得られる得点です。採用方法は機器と競技種別によって変わります。 |
| 整数点採点  | RING                   | 小数部分を切り捨て、整数の得点を使用します。                                         |
| 小数点採点  | DECIMAL                | 0.1 点刻みの得点を使用します。                                                       |
| インナー 10 | Inner Ten / X          | 中心付近の命中を表す判定です。範囲は標的と採点ゲージの定義に従います。               |
| ヒット数    | Hit count              | 所定の条件を満たした射撃の件数です。25m 決勝などで結果の集計に使用します。           |

採点ゲージは、着弾中心から得点圏への接触を判定するための直径です。標的の寸法や画面上の弾痕とは別に定義します。詳細は [標的・採点データ](./TARGET_SPEC.md) を参照してください。

## 接続と運用

| 用語           | 表記             | 意味                                                                                                 |
| -------------- | ---------------- | ---------------------------------------------------------------------------------------------------- |
| 射座           | Firing Point     | 選手が射撃する位置です。Director の射座割では番号で対応付けます。                                    |
| Lane           | Lane             | 射座で標的に接続するアプリです。射座番号や表示名とは別に、通信上の Lane ID を持ちます。              |
| 電子標的       | EST              | 着弾を電子的に検出・記録する標的装置です。                                                           |
| ブローカー     | MQTT broker      | Director と Lane のメッセージを中継するサービスです。                                                |
| 応答           | ACK              | Lane が操作の実行状況を返すメッセージです。`timeout` は Director が応答を確認できなかった状態です。  |
| 保持メッセージ | Retain           | 後から接続したアプリも受け取れるよう、ブローカーに保持する最新の値です。全履歴の保存ではありません。 |
| 規則定義       | Rule Pack        | 射数、時間、採点などを版ごとにまとめた Saika の定義です。対応機器の実機検証とは別です。              |
| 射場役員       | RO / CRO         | RO は Range Officer、CRO は Chief Range Officer の略です。                                           |
| 成績確認       | RTS verification | Results, Timing and Scoring の確認です。成績と根拠資料を照合し、承認を記録します。                   |
| 資料保全       | Evidence hold    | 調査に必要なデータの消去やリセットを保留する状態です。                                               |

実際の接続は [導入と接続](../GETTING_STARTED.md)、中断は [Director 運用ガイド](../director/OPERATIONS.md)、結果公表は [成績・データ保管ガイド](../director/RESULTS.md) を参照してください。
