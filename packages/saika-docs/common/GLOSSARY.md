# 射撃ドメイン共通用語集

Saika Lane で使用する射撃ドメイン用語の定義。

> 競技団体の規則本文ではなく、Saika Lane 内の用語を説明する資料です。公式な定義は [参照元](../SOURCES.md) から現行規則を確認してください。

---

## 競技構造

| 用語     | 英語                        | 説明                                                                                                                                                                                                                                                                                                                                                             |
| -------- | --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ステージ | Stage                       | 競技の段階。1つの種目は1つ以上のステージで構成される。Preparation もステージの1種                                                                                                                                                                                                                                                                                |
| シリーズ | Series                      | Stage 中に発射された Shot の列。指定発数（デフォルト10発、maxShots で設定可能）をまとめた単位                                                                                                                                                                                                                                                                    |
| フェーズ | Phase                       | 競技進行の各段階（IDLE → ACTIVE → SERIES_COMPLETE → STAGE_ENTERED → FINISHED）                                                                                                                                                                                                                                                                                   |
| ラウンド | Round                       | 競技の区分。ISSF では Elimination（予選）/ Qualification（本選）/ Final（決勝）/ Individual（個人戦）が定義されている。Elimination は Round としての使用（Qualification 前の絞り込み）と、Stage としての使用（Final 内の脱落ステージ）がある。小規模大会では Elimination ラウンドを省略し、直接 Qualification から開始することもある。将来追加される可能性がある |
| 種別     | EventType / CompetitionType | BR60S / BP60 など、競技の進行方法とルールを定義する分類                                                                                                                                                                                                                                                                                                          |

## 射撃モード

| 用語     | 英語        | 説明                                                                                                                                   |
| -------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 試射     | Preparation | 本射前の照準調整用の射撃。記録には含まれず、合計点にも加算されない。Preparation ステージ内で行う。Sighting（照準合わせ）とも呼ばれる。 |
| 本射     | Record      | 公式記録として扱われる射撃。合計点に加算される                                                                                         |
| 準備時間 | Preparation | 競技開始前の準備時間。試射はこの時間内に行う                                                                                           |

## 得点

| 用語       | 英語        | 説明                                                                                                                                            |
| ---------- | ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| 点数       | Score       | 着弾点に基づいて計算される得点。小数点採点の場合は 0.0〜10.9（0.1点刻み）、整数点採点の場合は 0〜10（小数点以下切り捨て）。種目によって異なる。 |
| 合計点     | Total Score | 本射モードの全ショットの点数合計                                                                                                                |
| 10点圏     | Ten Ring    | 標的の最も中心に近い得点圏。最高得点が得られる                                                                                                  |
| インナー10 | Inner Ten   | 10点圏のさらに中心（X圏と同義）。BR・AR 種目では AP（エアピストル）の外線ゲージを使用して判定される。詳細は TARGET_SPEC.md の X圏定義を参照。   |

## 射撃場設備

| 用語           | 英語                             | 説明                                                                       |
| -------------- | -------------------------------- | -------------------------------------------------------------------------- |
| 射座           | FiringPoint                      | 射撃場の個々の射座。番号で識別される                                       |
| 標的           | Target                           | 各射座に紐づく標的。Rapid Fire Pistol のように複数の標的が紐づく場合もある |
| レーン         | Lane                             | 射座と標的のセット。レーンを「射座」と呼称する場合もある                   |
| 射群 / リレー  | Relay                            | 射撃場のレーン数より参加者が多い場合に時間を区切って交代する仕組み         |
| 電子標的       | EST (Electronic Shooting Target) | 弾丸の着弾位置を電子的に検出し、座標データとして送信する標的装置           |
| 着弾点         | POI (Point Of Impact)            | 弾丸が標的に当たった位置。X/Y 座標（mm 単位）で表現される                  |
| ターゲット番号 | Target Number                    | 各レーンに割り当てられた標的の番号                                         |

## 種目

| 用語             | 英語           | 説明                                                                                                  |
| ---------------- | -------------- | ----------------------------------------------------------------------------------------------------- |
| 10m エアライフル | 10m Air Rifle  | 距離10m、空気銃使用。60発または40発で競う                                                             |
| 10m エアピストル | 10m Air Pistol | 距離10m、空気拳銃使用。60発または40発で競う                                                           |
| 50m ライフル     | 50m Rifle      | 距離50m、口径 .22 の小口径銃使用。3姿勢（膝射→伏射→立射、各20発）または伏射のみ（60発）の種目がある。 |

## 標的関連

| 用語       | 英語      | 説明                                               |
| ---------- | --------- | -------------------------------------------------- |
| クロスヘア | Crosshair | 標的中心を示す十字線                               |
| ゼロイン   | Zeroing   | 試射で照準を調整し、着弾点を標的中心に合わせる作業 |
