# Saika Docs

Saika Lane と Saika Director を使う人のための日本語マニュアルです。
画面上のボタンや項目は、実際の英語表記を「 」で示します。

Lane は射座の標的に接続し、着弾・得点を表示します。単独でも使用できます。
Director は複数の Lane の進行と大会成績を管理します。

## マニュアルの使い方

サイトでは「文書を検索」からキーワードを探せます。`Ctrl+K`（macOS は `Cmd+K`）でも開き、`Esc` で閉じます。スマートフォンでは右上のメニューから文書を選びます。

文書内の節へ移動するには「このページの目次」を使います。広い画面では右側、それ以外では文書の上部に表示され、押すと開きます。各見出しのリンクは、その節を共有するときに使えます。横に長い表や図は、左右にスクロールして読めます。

紙に残す場合はブラウザーの印刷機能を使い、印刷プレビューで表や図の改ページを確認してください。

操作ガイドでは日常の手順を説明します。設定値の範囲、データ形式、対応機器の詳細は、各手順からリンクする仕様資料を参照してください。

## バージョンとリリース

Lane・Director・Docs は同じスイートバージョンを共有します。
利用するアプリと同じ `v<version>` タグの文書を参照してください。文書は共有 GitHub Release のソースに含まれます。
本書の操作は、同じ版の [Lane](../saika-lane/) と [Director](../saika-director/) の実装を基にしています。
