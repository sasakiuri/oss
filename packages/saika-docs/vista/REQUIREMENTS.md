# Saika Vista の表示仕様

Saika Vista は、会場のモニターに着弾・得点・順位・競技進行を表示するアプリです。設定手順は [Vista 操作ガイド](../../saika-vista/README.md) を参照してください。

## 対応範囲

Windows・macOS・Linux に対応します。1台の PC に接続した複数のモニターと、複数 PC のモニターを1台の操作用 PC から設定できます。会場内のネットワークで動作し、操作画面は英語、選手名は日本語も表示できます。

対応する標準の個人競技は次のとおりです。

| 種目               | 予選・本選 | ファイナル    |
| ------------------ | ---------- | ------------- |
| 10m エアライフル   | `AR60`     | `AR60_FINAL`  |
| 10m エアピストル   | `AP60`     | `AP60_FINAL`  |
| 10m ビームライフル | `BR60S`    | `BR60S_FINAL` |
| 10m ビームピストル | `BP60`     | `BP60_FINAL`  |

配信・放送出力、時計専用画面、団体・混合団体・独自ルール、50m・300m・25m は対象外です。案内画像や選手紹介の巡回、画面の一括設定、プレビュー、設定ひな型、複数領域の合成、結果の外部配布、配信遅延、過去競技の検索・再生にも対応していません。

## データの提供元

| 接続構成      | 表示する情報                                                             |
| ------------- | ------------------------------------------------------------------------ |
| Lane のみ     | 選択した射座の標的・着弾・得点・射数・個別の競技進行                     |
| Director 連携 | 選手と射座の対応、射撃情報、競技順位、判定済みのファイナル進行、公表結果 |

Lane だけで接続する場合も、通信サービスの追加導入は不要です。競技操作と裁定は Lane・Director で行います。Vista は提供元の得点・順位・公表状態を表示し、採点や順位計算は行いません。

## 画面と表示対象

画面ごとに標的一覧、選手詳細、Director の順位・ファイナル表示、待機画面を選びます。表示対象、ページの密度と巡回間隔、拡大率、表示弾数は画面ごとに保存します。

- 着弾は全弾・現在シリーズ・直近の指定弾数で絞り込む。射数・合計は競技全体の値を保ち、拡大範囲外の着弾にも印を付ける。
- 射座固定では空き・切断した射座の位置を保つ。選手追従では Director が確定した射座移動と射撃履歴を反映する。
- 試射・本射・シリーズの切り替えに追従する。競技終了後も対象を保持し、次の競技へは手動で切り替える。
- 射座名は Lane に、選手の表示ラベルは選択した競技・セッションに保存する。提供元の選手登録は変更しない。
- 「Identify」で実画面を確認する。「Standby」はその画面だけを隠し、受信と保存を続ける。待機状態は再起動後も保持する。
- OS ログイン後の自動起動と、モニターごとの自動画面表示を設定する。モニターを交換した場合は再割当する。

## 得点・順位・時計

試射・本射・シュートオフ、実射の0点・射撃前・得点未提供を区別して表示します。座標のない射撃は標的上に描画しません。再取得した履歴で新着の演出は再生しません。

順位と公表状態は同じ更新で反映します。未公表・暫定公表・抗議中・公式公表・取り消し・要再確認は提供元の状態に従います。公表状態を再確認できない間は、保存した結果として表示します。

Director の全体時計と Lane の個別時計を表示します。中断・再開・追加時間を反映し、同期を確認できない間は時計の数値を隠すか、最後に確認した残時間と確認不能の状態を示します。時計がゼロになっても、Vista が競技や結果を確定することはありません。

## 保存と復元

取得データには提供元、競技・セッション、リセット世代、更新の版、競技・標的定義を保存します。初回接続と再接続では状態と履歴を取得し、接続成功、同期完了、履歴不足、対象なしを区別します。

終了画面も保存し、担当者が切り替えるまで保持します。再起動や提供元の次セッションへの移行後も、保存した対象の表示、ページ切り替え、待機を続けられます。

保存に失敗した場合は直前の正常なデータを保ち、エラーを表示します。未対応の保存形式は初期化せずに残します。不正なデータがあっても、他の対象は引き続き表示できます。復元後は提供元へ訂正と公表状態を再確認します。未受信・未保存のデータは復元できません。

## 端末登録と画面設定

接続先は会場ネットワークで自動検出するか、アドレスを入力します。実端末に表示された秘密情報で登録し、表示データの取得先と画面の操作元を管理します。

1台の表示用 PC を管理できる操作用 PC は1台です。管理を移す場合は、元の操作用 PC で登録を解除するか、表示用 PC で操作権限を取り消します。通信断で解除を確認できない場合は、解除待ちとして表示します。

画面設定は対象と更新順を確認して保存します。保存完了、データ同期、実画面の描画状況は別々に表示します。設定を適用できなかった画面は直前の設定を保ち、エラーを表示します。観客画面には操作パネルや認証情報を表示しません。

## 会場試験

以下は実機試験の目標です。100射座・12時間での検証は未完了です。自動テストの対象は [Vista 操作ガイド](../../saika-vista/README.md#validation-scope) を参照してください。

| 項目           | 条件                                                           |
| -------------- | -------------------------------------------------------------- |
| 射座           | 100射座                                                        |
| 射座用モニター | 各射座の後ろに1枚、計100枚                                     |
| 大型サイネージ | 60型以上を複数台                                               |
| PC 構成        | 1台に複数モニターを接続する構成と、複数 PC で分担する構成      |
| 通常表示の遅延 | Vista での受信から対象画面の描画まで、各画面の95%以上を1秒以内 |
| 連続運用       | 12時間                                                         |

100射座は試験規模です。製品やライセンスによる台数制限はありません。試験前に PC・OS・モニターの仕様と台数、ネットワーク、射撃頻度、履歴量、保存容量を決めます。Lane のみと Director 連携をそれぞれ測定します。

確認項目は、画面別の遅延・欠落・重複、CPU・メモリ・通信量、一斉接続と復旧、射座移動と訂正、保存失敗と復元、設定変更、端末の管理移管です。各 OS の自動起動、省電力、モニター交換、日本語名の視認性も確認します。

通常表示の遅延には、内部の待ち時間と画面への配布を含めます。提供元から Vista までの遅延、初回同期、復旧、設定適用、停止検出、待機からの再表示は別に測定し、許容時間を試験前に決めます。
