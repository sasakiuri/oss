# Saika Vista 競合比較と要件への反映

[要件定義](./REQUIREMENTS.md) / [文書一覧](../INDEX.md)

- 調査日：初回2026-09-10、追加2026-09-11。
- 目的：電子標的の観客表示製品と比較し、Vista の表示・会場運用に必要な要件の不足を確認する。
- 対象：SIUS、Megalink、Meyton、DISAG、Scopos、Sport Quantum、Kongsberg Target Systems の公式製品情報・マニュアル・更新情報。
- 状態：公開資料に基づく比較。実機での評価、性能測定、全製品・全機能の網羅調査は未実施。
- 本文の「確認事実」は資料に記載された機能。「提案」は Vista の利用条件に照らした判断であり、利用者との合意ではない。

## 1. 比較の前提

初回比較では Saika の既存実装と利用者の回答を中心にした要件定義に対し、標的の見せ方、多数画面の識別、巡回の読みやすさ、表示開始と待機への切替を具体化しました。これらは現在の F-25〜F-29へ反映済みです。追加調査では Scopos を含む5社の資料で、観戦を助ける表現、導入・対応版、規則変更、拡張の境界を検討しています。

競合製品が含む大会管理・採点・順位計算を、Vista の責任へ追加しません。Vista は Lane・Director の情報を表示するアプリです。Lane 単独時のランキング、団体順位、混合団体、広告や選手紹介の巡回、表示先グループは、確定条件に従って初期対象から外します。

資料に記載がない機能は「未確認」とし、非対応とは断定しません。古いマニュアルは操作要件の参考として扱い、現行版でも同じ挙動とは保証しません。競合との通信互換やデータ取り込みも、今回の調査から初期要件へ追加するものではありません。
