# 公開コンテンツ方針

Saika Docs に追加する内容は、次の条件を満たす必要があります。

- 投稿者自身が作成し、MIT License で提供する権限を持つこと。
- 第三者資料を利用する場合は、互換性のあるライセンスと必要な表示をファイル単位で記録すること。
- 競技規則、製品マニュアル、論文などは原文を収録せず、一次情報へのリンクと独自の要約を使うこと。
- 第三者のソースコード、抽出済みコード、バイナリ、画像、画面、帳票テンプレートを持ち込まないこと。
- パケットキャプチャ、復号情報、非公開 API、アクセス制御を回避して得た情報を持ち込まないこと。
- 相互運用文書は、公開済みの自作実装と公式一次情報を根拠にし、「Saikaが受理する形式」と
  「メーカーの公式仕様」を明確に区別すること。
- 未確認のコマンド、チェックサム、電気特性、動作保証を推測で補わないこと。
- 契約、秘密保持義務、雇用上の職務著作、営業秘密に抵触しないことを投稿者が確認すること。
- 個人情報、認証情報、実在選手の記録、機器固有 ID を削除または匿名化すること。
- 商標は対象の識別に必要な範囲でのみ使用し、提携や公式性を示唆しないこと。

出典または権利関係が不明な内容は、確認が完了するまでこのパッケージに追加しません。
