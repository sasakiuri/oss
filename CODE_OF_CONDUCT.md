# Contributor Covenant Code of Conduct

This project has adopted the [Contributor Covenant](https://www.contributor-covenant.org/) version 2.1 as its code of conduct.

For the full text, see <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

## Reporting

Report unacceptable behavior via:

- **Private**: Email the maintainer directly through their [GitHub profile](https://github.com/sasakiuri).
- **Public (non-sensitive)**: Open a thread in [GitHub Discussions](https://github.com/sasakiuri/oss/discussions).

All reports will be reviewed promptly and handled confidentially.
