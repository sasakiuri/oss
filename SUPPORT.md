# Support

Thank you for using this project. Here is how to get help.

## Bug Reports

Please open an issue using the appropriate [issue template](https://github.com/sasakiuri/oss/issues/new/choose).

## Security Vulnerabilities

Do **not** open a public issue for security vulnerabilities. Instead, please use [GitHub Security Advisories](https://github.com/sasakiuri/oss/security/advisories) to report them privately. See [SECURITY.md](SECURITY.md) for details.

## Feature Requests

Open an issue via [GitHub Issues](https://github.com/sasakiuri/oss/issues/new/choose) describing the use case and expected behavior.

## General Questions

For questions, ideas, or general discussion, please use [GitHub Discussions](https://github.com/sasakiuri/oss/discussions).

---

This is a small open-source project maintained in spare time. Response times may vary. Your patience is appreciated.
